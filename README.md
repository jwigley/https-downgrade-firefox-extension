# HTTPS Downgrade Firefox Extension

Redirects requests from HTTPS to HTTP for a configurable list of domains.

Modern Firefox is great in that it defaults to HTTPS for all requests. However this can be annoying for services you have setup on your local network, where you can't or don't want to setup SSL certificates for.

This extension saves you from the hassle of Firefox first showing you an error screen, then you having to edit the URL to remove the 's' from 'https' to load the intended page.
